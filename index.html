One-time setup — add your GitHub token

This app reads your recommendations from the GitHub repo and writes back actions (mark watched, pin, hide). It needs a personal access token scoped to this repo. After you save it once, every device you sign in on will inherit it automatically.

  1. Open github.com/settings/tokens?type=beta and create a fine-grained PAT.
  2. Repository access: Only select repositories → jcpeters08/tv-concierge.
  3. Permissions → Repository → Contents: Read and write.
  4. Paste the PAT below and click Test & save. It is encrypted with a server-side key and stored on the auth Worker.
